# Theatrelogue
A website catalogue of almost every popular Broadway musical with almost all relevant information about it. Solely developed by Jazz and deployed using Netlify.

## Features
**I. Frontpage Posters**
- Basically a summarized collection of all the musicals currently present in the website. I'll always be open to adding more!

**II. Animations**
- Smooth and functional animations related to the current musical being displayed, with cool interactive gimmicks for each musical that the user can play around with.

**III. Information**
- Almost all relevant and important information regarding each musical is present and stylistically displayed on the website.

**IV. Musical Playlist/Players**
- Each musical has a playlist with all its complete and official released songs, which can be played by the user.

## How to Run
1. Go to [this link](https://theatrelogue.netlify.app/), no need to install anything on your device.
2. Browse around the website to view all the added Broadway musicals and their relevant information.

**If you would like to use the source code:**

1. Clone the repository.
2. Run the following command in your terminal in order to download the project's needed packages: `npm install` or `npm i`
3. Utilize `npm run build-css` to see live Tailwind CSS changes.

## Tech Stack/Dependencies
- HTML
- CSS/Tailwind CSS
- JavaScript
- GSAP
